# ARISE AI — Prototype

This repository contains the ARISE AI frontend prototype: a single-file demo (index.html) with demo data, onboarding, dashboard, AI assistant UI, and a polished Focus Mode (Pomodoro) with session tracking.

Files
- index.html — Demo single-file app (Alpine.js + Tailwind CDN). Open in browser to run.
- assets/ — SVG logo assets and social preview SVG.
- manifest.webmanifest — PWA manifest example.

How to use
1. Clone the repo or download ZIP from GitHub.
2. Open index.html in a browser (Chrome/Edge/Firefox). No build step required for this static demo.
3. Use "Demo Mode" to load the sample profile quickly.

Next steps
- Run the included icon export scripts (Node + sharp) to generate PNG fallbacks and a social preview PNG. See the README in the web UI for tips.
